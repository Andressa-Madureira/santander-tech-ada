# We Form 📑

We Form é um projeto desenvolvido durante a trilha Santander Tech +, em parceria com a Ada Tech, com o objetivo de facilitar o cadastro de entidades e seus campos de atuação. Este projeto foca na criação de uma interface visual moderna e funcional, ideal para aplicações com demandas de cadastro.

📌 Destaques do Projeto
<ul>
  <li>Interface limpa e acessível: Estruturada em HTML5 com estilização aprimorada em CSS3, utilizando recursos modernos como Grid Layout e Flexbox</li>
  <li>Cadastro intuitivo: Permite o registro de entidades de forma organizada, com campos para nome, campo de atuação e pontos de coleta</li>
</ul>

⚙️ Tecnologias Utilizadas
<ul>
  <li>HTML5: Para estruturação do conteúdo</li>
  <li>CSS: Estilização responsiva utilizando grid e flexbox para uma disposição moderna e eficiente</li>
  <li>Google Fonts: Para uma tipografia elegante e profissional</li>
</ul>

🎯 Motivação

Este projeto foi uma oportunidade de consolidar habilidades em desenvolvimento front-end, com foco em criar interfaces amigáveis e organizadas. Representa um passo importante no meu aprendizado e carreira na área de tecnologia.
